# European Hospital Capacity and Activity  

## Project status

Work in progress.

## Objective

This project analyses hospital capacity and activity in Spain, Portugal, France, Italy and Germany using official Eurostat data. 

## Main questions

1. How has hospital bed availability changed over time?
2. How has hospital activity evolved across countries?
3. How does Spain compare with the selected European countries?
4. Which diagnostic groups show the largest differences?
5. How complete and comparable are the available data?
